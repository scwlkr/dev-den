# A local room with a shared, validated review protocol

Adapt roast-room's session files, live events, weighted option scores and opening/debate/ratification protocol. Use Node's standard library and the existing prepared knowledge. Keep the MIT attribution. The room uses provisional pixel illustrations; final portraits and style remain open.

The agent skill and optional API adapters submit the same validated JSON cards. The browser can prepare a brief, adjust a recommended five-to-seven-person council, run configured APIs, observe agent sessions, replay saved reviews and export reports. Every review shares one fixed brief and relevant project context. Missing essential context is clarified before starting.

During reviews, use only prepared advisor knowledge and retained evidence. No search or source-collection tools are exposed to advisors. Historical quotations must match the selected advisor, source, passage and attribution. Narrative output is paraphrase; applied reasoning is labeled simulation. Source checks establish text membership, not independent audio or semantic verification.

Keep API credentials on the server. Bind the room to loopback, require a session token for browser writes and preserve local sessions outside Git. Reserve costs before API requests, retain uncertain outcomes, and never automatically repeat a possibly charged request. A stopped review resumes from saved validated steps. The initial live demonstration is capped at $0.75 of existing credits, separately recorded from the unchanged collection ledger.
