# Use a hybrid source collection pipeline

Use OpenAI API credits and Terra models for source discovery, interpretation, and advisor knowledge compilation, with ordinary retrieval tools handling page/document extraction, deduplication, and quotation-text checks. Keep stages resumable and source material attributable so an interruption does not require repeating completed work and model-generated summaries do not replace the evidence they summarize.

Include authored articles, papers, technical discussions, talks, interviews, and substantial livestream segments, distinguishing each developer's own words from other speakers and quoted material. Start with written sources and available transcripts; recordings needing additional transcription are identified separately.
