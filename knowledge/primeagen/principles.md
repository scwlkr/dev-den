# ThePrimeagen (Michael Paulson): principles

Prepared pilot knowledge; source coverage and limitations are reported below.

- **documented**: Match the technique to a problem that reveals its value: his maze exercise made recursion useful to him in a way simple list traversal had not. ([primeagen-e9f1dd5d440749](https://lexfridman.com/theprimeagen-transcript/) / evidence primeagen-e9f1dd5d440749-b0d0cf7bcc5f; [primeagen-e9f1dd5d440749](https://lexfridman.com/theprimeagen-transcript/) / evidence primeagen-e9f1dd5d440749-2db2e561e07c)

- **documented**: Understand existing code and its edge cases before replacing it. Separately, building a scratch implementation can be valuable when the objective is learning rather than replacing production code. ([primeagen-e9f1dd5d440749](https://lexfridman.com/theprimeagen-transcript/) / evidence primeagen-e9f1dd5d440749-20bb07e6efcf; [primeagen-e9f1dd5d440749](https://lexfridman.com/theprimeagen-transcript/) / evidence primeagen-e9f1dd5d440749-fbb2139967b5)

- **documented**: Repeated practice can develop fluency and reduce distracting lookup tasks. He describes hard work as a way to discover smarter methods, not as a substitute for them. ([primeagen-e9f1dd5d440749](https://lexfridman.com/theprimeagen-transcript/) / evidence primeagen-e9f1dd5d440749-475ccf7121a4; [primeagen-e9f1dd5d440749](https://lexfridman.com/theprimeagen-transcript/) / evidence primeagen-e9f1dd5d440749-17964b86931f; [primeagen-e9f1dd5d440749](https://lexfridman.com/theprimeagen-transcript/) / evidence primeagen-e9f1dd5d440749-db2fb943247b)

- **documented**: Learn enough about typing and the editor to leave more attention for the problem, but do not equate a particular editor with programming ability. ([primeagen-e9f1dd5d440749](https://lexfridman.com/theprimeagen-transcript/) / evidence primeagen-e9f1dd5d440749-8a371b1f7f18; [primeagen-e9f1dd5d440749](https://lexfridman.com/theprimeagen-transcript/) / evidence primeagen-e9f1dd5d440749-87c06deb12ac)

- **documented**: Coupled, logic-heavy applications benefit from tests because a local change can have effects elsewhere. He also structures teaching examples to make their core logic easier to test. ([primeagen-e9f1dd5d440749](https://lexfridman.com/theprimeagen-transcript/) / evidence primeagen-e9f1dd5d440749-b65289f13b6a; [primeagen-b3806082f08ddf](https://theprimeagen.github.io/ts-go-rust/lessons/projector/typescript-projector) / evidence primeagen-b3806082f08ddf-53f36ced98e3)

- **documented**: Commit early to protect work, while recognizing that broad staging patterns can include unintended files. Squashing can later make personal development history easier to review. - **documented**: Avoid rewriting public branch history; he considers cleaning up a personal branch more acceptable. A hard reset can destroy tracked and staged work, while a revert creates an inverse commit and can itself conflict. - **documented**: Reading code and writing it are different skills. He suggests considering disabling Copilot when learning something new if assistance is masking gaps in independent understanding.
