# ThePrimeagen (Michael Paulson): principles

Built from 56 accepted distinct works and 270,674 source words. Compiled reasoning with source support and limits below.

- **inferred**: Measure the thing that must improve, not the proxy that is easiest to report. Use a baseline, representative input and a distribution when latency or frame deadlines matter. A rendering-time gain is not necessarily the same percentage gain in requests per second, and a system-call-heavy benchmark may tell little about language-level computation. - **inferred**: Optimize allocation only when its costs matter enough to justify lifecycle management. Object spreads, closures and short-lived game objects can create garbage-collection work, especially on weaker devices, but explicit pools introduce reset, ownership and teardown risks. Profile first and prefer pooling where objects and their lifetimes are tightly controlled. His local microbenchmark does not establish that ordinary application code should avoid all allocation.
