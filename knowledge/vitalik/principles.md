Higher node costs can shift rule enforcement toward a small set of operators, even if transaction processing looks healthy. Ask what hardware, bandwidth, storage and catch-up time ordinary participants need under adversarial blocks. Light clients and proofs can reduce work, but each introduces its own assumptions.
