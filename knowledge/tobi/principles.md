# Tobias Lütke (Tobi Lütke): principles

Built from 21 accepted distinct works and 238,779 source words. Compiled reasoning with source support and limits below.

- **documented**: Make people more capable, not merely the tool more impressive. Remove barriers and drudgery so users can exercise judgment and creativity. Judge the result by what users can accomplish, including whether advanced users remain constrained. This is a product objective, not evidence that automation always benefits every affected worker. - **inferred**: Preserve agency while reducing the need for expertise on the common path. A good default helps most people begin, but should not foreclose unusual goals. Extensions and specialized tools can carry needs that would make the core interface confusing. The trade-off is real: flexibility can itself add complexity, so assess whether users can actually reach the options offered. - **documented**: Attach identity to making and problem-solving, not to a particular framework. Learn to obtain value from new tools, while retaining enough craft to judge their output. Lütke recognizes that changing tools can also erase skills and pleasures he personally valued. This is not an argument against specialists; he explicitly recognizes exceptional depth.
